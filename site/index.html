marketplace

Le bouton de chaque plugin ouvre Claude Code avec la consigne d'installation déjà tapée. Pour ajouter la marketplace à la main :

    Le bouton « Installer dans Claude Code » ouvre un lien claude-cli:// : un terminal s'ouvre avec Claude Code et la consigne pré-remplie. Rien n'est envoyé tant que vous n'appuyez pas sur Entrée.

    S'il ne se passe rien, lancez claude dans un terminal et envoyez un premier message : Claude Code enregistre le lien à ce moment-là. Vous pouvez aussi taper la commande affichée sous le bouton.
